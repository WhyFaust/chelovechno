# Человечно

Русский | [English](README_en.md)

Навык для AI-агента, который пишет авторские тексты с понятной мыслью и живым голосом: посты, статьи, письма, сценарии, описания, названия, комментарии и ответы. Помогает написать с нуля, отредактировать черновик, адаптировать материал или найти свежую тему.

Русский в приоритете; другие языки по запросу. Тон и форма зависят от задачи и адресата. Навык работает в вашей модели и среде, без собственного сервера, API-ключа и подписки. Для свежих тем агенту нужен поиск или браузер.

## Быстрый старт

Установите через [Skills CLI](https://skills.sh/docs):

```bash
npx skills add WhyFaust/chelovechno --skill chelovechno
```

Выберите агента в установщике и дайте задачу. Например, в Codex:

```text
$chelovechno Напиши полезный пост для Telegram о выборе первого блокнота.
Пустые страницы подходят для рисунков, точки помогают выравнивать строки.
Спокойно, без продажи и придуманного личного опыта. Только готовый текст.
```

Для обычного чата скачайте полный файл **chelovechno.md** или **chelovechno_en.md** из [последнего релиза](https://github.com/WhyFaust/chelovechno/releases/latest). Для ручной установки скопируйте всю папку `skills/chelovechno/`.

[Подробная установка, английские инструкции и примеры запросов](docs/usage.md).

## Что можно поручить

| Задача | Что передать агенту |
|---|---|
| Написать текст | Тему, читателя, факты и место использования |
| Отредактировать | Черновик и то, что нужно сохранить |
| Адаптировать | Исходный материал и нужный формат: пост, письмо, описание или устная речь |
| Ответить в обсуждении | Пост, нужную реплику, поздние уточнения и свою позицию |
| Найти свежую тему | Предмет, период поиска и аудиторию |
| Сохранить свою манеру | Образцы текстов без переноса чужих историй и биографии |

По умолчанию агент возвращает один готовый результат. Сохраняет цены, сроки, оговорки и рабочий способ заказа. Обычное объяснение не дополняет продажей без просьбы. Новым текстам задаёт обычные двойные кавычки `"..."`; точные цитаты сохраняет. Существенные пробелы уточняет одним вопросом.

Посмотрите [учебные тексты](examples/texts.md) и [пример с настоящим поиском](evals/reports/live-search.md). Качество зависит от модели и материалов; навык не обещает охват или результат в AI-детекторах.

## Проверка и сборка

Из корня репозитория, с Node.js 22 или новее, без установки зависимостей:

```bash
node --test scripts/prepare.test.mjs scripts/release-version.test.mjs
node scripts/prepare.mjs
```

Сборка создаёт `dist/chelovechno.md` и `dist/chelovechno_en.md`. Автотесты проверяют упаковку и релизный процесс; поведение модели оценивается отдельно по [сценариям](evals/README.md).
