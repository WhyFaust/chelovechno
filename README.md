# Человечно

Навык для AI-агента, который пишет посты с понятной мыслью и живым голосом: подписи к фото в Instagram, заметки в Threads и X, тексты для Telegram. Может написать с нуля, отредактировать черновик или сам найти свежий повод по вашей теме.

Русский в приоритете; другие языки — по запросу. Тон зависит от задачи: личный, экспертный, от лица бренда. Если дать образцы своих текстов, агент будет учитывать их ритм, словарь и манеру общения.

```text
$chelovechno Найди свежую новость о городской фотографии за последние 3 дня
и напиши пост для Telegram. Читатели — начинающие фотографы.
Спокойно, с конкретикой, без рекламы и придуманного личного опыта.
```

Навык работает в вашей модели и среде. У него нет собственного сервера, API-ключа и подписки. Для свежих тем агенту нужен доступ к поиску или браузеру.

## Установка

В агент с поддержкой [Agent Skills](https://agentskills.io):

```bash
npx skills add WhyFaust/chelovechno --skill chelovechno
```

Установщик предложит выбрать агента. Для установки на уровне пользователя в Codex:

```bash
npx skills add WhyFaust/chelovechno --skill chelovechno --agent codex --global
```

Для Claude Code замените `codex` на `claude-code`; для Cursor — на `cursor`. Для всех агентов, которые поддерживает установщик:

```bash
npx skills add WhyFaust/chelovechno --skill chelovechno --agent '*' --global
```

Команда использует [Skills CLI](https://skills.sh/docs); для неё нужен Node.js с npm. Для ручной установки Node.js не нужен.

### Вручную

Скачайте репозиторий и скопируйте **всю** папку `skills/chelovechno`, сохраняя `references/` и `agents/`:

| Среда | Папка пользователя | Папка проекта |
|---|---|---|
| Codex | `~/.agents/skills/chelovechno/` | `.agents/skills/chelovechno/` |
| Claude Code | `~/.claude/skills/chelovechno/` | `.claude/skills/chelovechno/` |

`~` в Windows — каталог пользователя, обычно `C:\Users\имя`. Для другой среды используйте её документированную папку навыков. Не заменяйте существующий навык без сохранения своих правок.

Формат соответствует Agent Skills. Фактическое обнаружение и синтаксис вызова зависят от агента: в Codex — `$chelovechno`, в Claude Code — `/chelovechno`; также можно попросить написать пост обычными словами. Изменения навыков Codex обычно обнаруживает автоматически; если навык не появился, перезапустите среду. [Документация Codex](https://learn.chatgpt.com/docs/build-skills), [Claude Code](https://code.claude.com/docs/en/skills).

### В обычном чате или своей системе

Скачайте **chelovechno.md** из [релиза](https://github.com/WhyFaust/chelovechno/releases/latest). Это полная версия навыка одним файлом: основные инструкции и справочники. Приложите её к чату или используйте как инструкцию в своей системе, затем дайте задачу. Для локальной сборки файла: `node scripts/prepare.mjs`.

Один файл удобен там, где нельзя установить папку навыка. Он не добавляет модели браузер: без поиска она сможет писать по вашим материалам, но не должна придумывать свежие новости. Загрузка Markdown как инструкции зависит от возможностей конкретного чата.

## Что попросить

**Подпись к фото**

```text
Напиши 3 подписи для Instagram. На фото — пустой пляж после дождя.
Коротко, спокойно, без философии. Не придумывай историю поездки.
```

**Пост из мысли**

```text
Пост для Threads: когда весь выходной планируешь, он начинает напоминать
ещё один рабочий день. Хочу лёгкую самоиронию, без советов читателю.
```

**Свежая тема → готовый пост**

```text
Сам найди свежий повод о любительском беге и напиши пост для Telegram.
Аудитория — люди, которые бегают для себя. За последние 3 дня.
Объясни, чем это полезно. Источники вынеси отдельно от текста.
```

**Один материал для разных площадок**

```text
Адаптируй эту заметку для X, Threads и Telegram.
Сохрани факты, но выбери подходящие начало и объём для каждой площадки.
[заметка]
```

**Ваша манера**

```text
Вот несколько моих постов: [образцы]. Возьми их ритм и интонацию.
Новый пост — про [тема]. Факты: [материалы].
Истории и биографию из образцов в новый текст не переноси.
```

**Редактура**

```text
Сделай текст живее. Сохрани цену, сроки, ссылки и все оговорки.
Верни только готовый текст: [черновик].
```

По умолчанию агент выдаёт один готовый вариант. Существенные пробелы уточняет вопросом с вариантами ответа. Уже известные настройки повторно не спрашивает.

## Как работает поиск

Если запросу нужна актуальность, агент сначала ищет материалы, открывает их и проверяет ключевые утверждения. Обычный период — последние **72 часа** относительно времени запуска. Для медленной темы он может расширить окно до 7 дней, сообщив об этом. Указанный вами период имеет приоритет.

Агент различает дату публикации и дату события, ищет первоисточник и не считает перепечатки независимыми подтверждениями. Для обычного объявления достаточно его автора; спорные выводы требуют дополнительных оснований. Старый запуск в свежей статье не становится новой разработкой.

После готового поста идёт отдельная заметка для автора: время проверки, период, прочитанные источники и существенные ограничения. Можно попросить только текст; тогда нужные ссылки и оговорки остаются внутри него. Если проверка не удалась, агент сообщает об этом и предлагает дать материалы или выбрать другую тему.

Поиск запускается вашим запросом. Мониторинг по расписанию и автопубликация требуют возможностей среды и отдельной настройки.

## Подход

Основной сценарий: понять задачу, найти подходящую мысль или свежий материал и написать пост для конкретного читателя.

При правке сохраняются смысл, факты и голос. Тире, вопросы и отдельные слова не запрещены сами по себе; искусственная небрежность тоже не считается человечностью. Статьи о письме и документация — в [SOURCES.md](SOURCES.md).

## Примеры и проверка

- [Примеры готовых постов](examples/posts.md) по вымышленным брифам с явно заданными фактами.
- [Пример с настоящим поиском](evals/live-search.md): свежая публикация, проверенный источник и готовый пост.
- [Сценарии проверки](evals/README.md): голос, точность, разные площадки, свежесть и отказ от выдуманных новостей.
- [Проверка примеров](evals/smoke-results.md): что просмотрено вручную и чего эта проверка не доказывает.

Для разработки нужен Node.js 22 или новее. Без установки зависимостей:

```bash
node scripts/prepare.mjs
```

Команда проверяет структуру, локальные ссылки и комплектность навыка, затем собирает `dist/chelovechno.md`. Эти проверки также запускаются в GitHub Actions. Они проверяют упаковку, а не «процент человечности» текста. Изменения поведения проверяются на сценариях из `evals/`.

Качество текста зависит от модели, материалов и задачи. Навык не определяет авторство текста и не обещает результат в AI-детекторах. Самостоятельно найденные новости требуют проверки источников; личный опыт автора агенту всё равно нужно сообщить.
