# Agent Reach как дополнение

Русский | [English](agent-reach_en.md)

[Agent Reach](https://github.com/Panniantong/agent-reach) предоставляет отдельные инструменты поиска и чтения. Человечно отвечает за выбор материала, проверку и текст. Дополнение необязательно: имеющиеся поиск, браузер и коннекторы продолжают подходить.

## Подключение

Если хотите установить дополнение, используйте актуальную [инструкцию автора](https://github.com/Panniantong/Agent-Reach/blob/main/docs/install.md). Например, отдельным запросом агенту:

```text
Установи Agent Reach по официальной инструкции:
https://github.com/Panniantong/Agent-Reach/blob/main/docs/install.md
Подключи нужные мне каналы. Вход в аккаунты и выбор сессий согласуй со мной.
```

Пакет с именем `agent-reach` в PyPI не является этим проектом, как предупреждает его автор. Источник установки указан в инструкции GitHub. В зависимости этого репозитория ничего добавлять не нужно.

После установки проверьте версию и доступные каналы:

```bash
agent-reach version
agent-reach channels
```

Это команды из изученной документации версии 1.6 и новее. Для другой версии используйте её справку. Нужный канал проверяется отдельно от наличия программы.

## Использование с Человечно

```text
$chelovechno Найди свежий повод о фотографии за последние 3 дня
и напиши пост для моего канала. Если для чтения источника пригодится
уже подключённый Agent Reach, используй его. Источники покажи отдельно.
```

Агент следует установленному навыку Agent Reach и использует его для чтения, когда это помогает задаче. Дата события, исходный источник, оговорки и полнота прочитанного проверяются так же, как при обычном поиске. Стилевой пример из соцсети не подтверждает факты из чужого поста.

Если дополнение отсутствует или канал недоступен, агент использует другие доступные инструменты либо сообщает о пробеле. Обычная просьба написать текст не запускает установку и вход в аккаунты.

## Границы доступа

По [документации, проверенной 29 октября 2026 года](https://github.com/Panniantong/Agent-Reach/blob/14c213405669414492bda0f8d52cc6531d062c45/docs/README_en.md), Reddit является опциональным каналом с входом, X экспериментальным каналом с входом. Threads в опубликованной таблице отсутствует. Это описание проверенной версии, не постоянная таблица поддержки для Человечно.

Некоторые каналы могут использовать сессию существующего браузера. Установка, выбор аккаунта и доступ к сессии являются отдельной настройкой. Не передавайте ключи и cookies в тексты, исходники проекта или публичные отчёты. Дополнение не даёт разрешения публиковать, отправлять сообщения или обходить ограничения источника.

В изученных [правилах работы с браузером](https://github.com/Panniantong/Agent-Reach/blob/14c213405669414492bda0f8d52cc6531d062c45/docs/cloakbrowser.md) и [сессиями](https://github.com/Panniantong/Agent-Reach/blob/14c213405669414492bda0f8d52cc6531d062c45/agent_reach/skill/references/sessions.md) описаны отдельный CloakBrowser/Chrome и перенос входа из Chrome через подключённый мост. Подключение уже открытого Firefox не подтверждено. Вход в Firefox сам по себе не означает вход в Agent Reach; используйте доступное управление браузером или отдельную настройку дополнения по выбору пользователя.

Интеграция проверена на уровне документации и инструкций навыка. Установка Agent Reach и вход в его каналы в рамках этого ревью не выполнялись.
